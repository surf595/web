# Private Psychotherapy Practice Website

Спокойный, минималистичный сайт частной психологической практики на Next.js App Router.

## Stack
- Next.js (App Router)
- TypeScript / TSX
- Tailwind CSS

## Быстрый старт
```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Структура
- `app/` — страницы и роутинг
- `components/` — переиспользуемые UI и секции
- `data/` — редактируемый контент сайта
- `lib/` — типы и вспомогательные сущности
- `public/` — статические ассеты

## Контент
Большая часть текстов, навигации, FAQ, услуг и контактов хранится в `data/*`.

## Продакшн
```bash
npm run build
npm run start
```

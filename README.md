# Сайт частной практики психолога (Таллин)

Русскоязычный сайт частной психотерапевтической практики на Next.js App Router.

## Технологии
- Next.js (App Router)
- TypeScript / TSX
- Tailwind CSS

## Запуск
```bash
npm install
npm run dev
```

## Структура
- `app/` — страницы, sitemap/robots, статьи
- `components/` — UI-компоненты и секции
- `data/` — редактируемый контент
- `lib/` — типы
- `public/` — статические ассеты

## Основные маршруты
- `/` — Главная
- `/о-специалисте`
- `/с-чем-я-работаю`
- `/как-я-работаю`
- `/формат-и-стоимость`
- `/faq`
- `/контакты`
- `/политика-конфиденциальности`
- `/политика-персональных-данных`
- `/статьи`

## Продакшн
```bash
npm run build
npm run start
```
